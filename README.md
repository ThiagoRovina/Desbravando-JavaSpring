# ☕ Desbravando Java Spring

Projeto de estudo e prática com **Java e Spring Boot**, criado para consolidar conceitos de desenvolvimento backend e construção de aplicações web com o ecossistema Spring.

## 🎯 Objetivo

Evoluir de exercícios isolados para uma aplicação estruturada, praticando organização de projeto, desenvolvimento de endpoints e uso das principais convenções do Spring Boot.

## 🚀 Tecnologias

- Java
- Spring Boot
- Maven

## 📁 Estrutura

A aplicação principal está localizada no diretório `demo/`.

```text
demo/
└── src/
    └── main/
        └── java/
            └── com/javaspring/demo/
```

## 📚 Aprendizados praticados

- Estrutura de projetos Spring Boot.
- Organização de código Java em pacotes.
- Inicialização e configuração de aplicações Spring.
- Evolução incremental por commits e experimentação prática.

## ▶️ Como executar

Com Java e Maven configurados:

```bash
cd demo
./mvnw spring-boot:run
```

No Windows:

```bash
cd demo
mvnw.cmd spring-boot:run
```
